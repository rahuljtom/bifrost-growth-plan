# Bifrost growth plan

A 90-day growth plan for [Bifrost](https://github.com/maximhq/bifrost), the open-source LLM gateway, written as a take-home for Maxim AI.

- `index.html`: the plan
- `exit-plan.html`: v0 draft of the AI Model Exit Plan template the plan is built around

Facts are tagged `v` (verified by the author, 21–22 Nov 2026), `r` (reported by press or analysts) or `a` (assumption). Independent candidate work; not affiliated with or endorsed by Maxim AI.
